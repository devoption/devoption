# Security

DevOption is an unreleased scaffold. No production-ready or supported release
line exists yet. There is no guaranteed response or remediation time.

Do not publish secrets, exploit details, or private data in issues or PRs.
Check the repository's [Security page](https://github.com/devoption/devoption/security)
for a **Report a vulnerability** button. If it is available, use it to send a
private report with the affected commit, impact, and safe reproduction steps.

Private vulnerability reporting was **not enabled at bootstrap**. If the button
is unavailable, open a public issue containing only a request to establish a
private reporting channel, with no vulnerability details. Wait for a maintainer
to provide that channel before sharing sensitive information. No private email
address or other reporting channel is currently designated by this repository.

For ordinary bugs without security implications, use the bug report template.
