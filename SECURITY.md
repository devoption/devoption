# Security

DevOption is an unreleased development preview. No production-ready or supported
release line exists yet. There is no guaranteed response or remediation time.

Do not publish secrets, exploit details, or private data in issues or PRs.
Use the repository's [private vulnerability reporting form](https://github.com/devoption/devoption/security/advisories/new)
to send a private report with the affected commit, impact, and safe reproduction steps.

Private vulnerability reporting was verified enabled on 2026-10-17
(America/New_York). The [maintainer checklist](docs/maintainers.md#verified-repository-settings)
records the read-only settings check. If the private form is unavailable, open a
public issue containing only a request to establish a private reporting channel,
with no vulnerability details. Wait for a maintainer
to provide that channel before sharing sensitive information. No private email
address or other reporting channel is currently designated by this repository.

For ordinary bugs without security implications, use the bug report template.
